# Histórico do OPA

Pipeline exclusivamente offline para transformar uma exportação JSONL em amostras anonimizadas de avaliação. O OPA não participa do atendimento em produção e a saída traz `publish_to_rag: false` e `approved: false` por padrão.

Nenhuma conversa deve ser incorporada à base sem revisão de um responsável. Use um salt forte, temporário e fora do repositório; apague os arquivos brutos após o processo aprovado de retenção.
